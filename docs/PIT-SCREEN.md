# 피트 스크린

- 근거: `부품설계.pdf` 254~255쪽의 고정 브라켓·전면 철판·M6x10 체결·하단 100~300mm 간격. 사용자 사진 2026-09-20 233834는 얇은 철판의 형태만 참고한다. 사진의 색상과 주변 설비 배치는 적용하지 않는다.
- 후면 균형추와 피트 작업 공간 사이의 고정 노란색 보호판이다. 운행 중 이동하거나 접히지 않으며 운행 FSM을 제어하는 센서가 아니다.
- 형상 원본: `blender/scripts/pit_screen.py` → `models/gltf/pit_screen.glb`. Blender `T(x,y,z)=(x,-z,y)` 변환 후 앱에서 추가 축 회전 없이 사용한다.
- 너비는 `js/config.js`의 `S.CWT_W`를 Python에서 읽어 +220mm로 만든다. GLB extras의 `pitScreen`이 나머지 치수와 장착 위치의 원본이다. 로더는 레일 간격이 달라지면 재내보내기를 요구한다.
- 현재 모델: 폭 1600mm, 높이 2000mm, 철판 두께 1.5mm, 두 장 사이 이음 2mm, 후면 절곡 18mm. 이 수치들은 시뮬레이터 형상 선택이며 PDF에 명시된 제작 치수로 해석하지 않는다.
- 하단은 `Y0+200mm`다. 20mm 바닥 마감을 제외한 실제 보이는 간격은 180mm다. 철판 중심 Z는 `CWT_CENTER_Z+150mm`다.
- 4단 분할 가로 브라켓은 판 뒤에 밀착하고 중앙 절곡을 피한다. 바깥 리턴 암과 레일 배면 클립은 균형추 프레임·가이드슈 이동 경로를 피한다. M6x10 볼트·와셔·육각 머리를 표현한다.
- `js/environment.js`의 `buildPitScreen()`이 `pitGrp`에 장착한다. 판과 브라켓은 `M.paint(0xffc400)`, 체결부는 `M.ss()`를 공유한다. 정적 메시 4개, 삼각형 2,904개다.
- `node tools/verify_pit_screen.mjs`: Live Server 캐시 비활성화, 하단 간격, 실제 카 형상의 후면 여유, 균형추 각 메시의 전 이동 범위와 스크린 삼각형 경계 간섭, 최상층 운행 중 고정 유지, 정면·후면·철판·균형추 최하단 화면을 확인한다. 카 간극 검사는 최하층·스크린 높이 내 일반 메시 정점 기준이며 인스턴스 메시를 포함한 정밀 물리 충돌 해석은 아니다.
- 실기기 모바일 조작·성능은 PC 검증과 별개로 확인해야 한다.
