- [PFEIFER DRAKO 기술자료](https://www.pfeifer.info/out/assets/PFEIFER-DRAKO_STEEL-WIRE-ROPES-IN-ELEVATORS_TECHNICAL-INFORMATION_EN.PDF)는 로프 장력 차이·홈의 접촉압·미끄럼과 마모의 관계를 설명한다. 따라서 로비층이라는 이유만으로 항상 최대 마모점이라고 단정하지 않는다. 반복 굽힘과 기동·정지, 하중, 홈 상태, 장력, 윤활 상태에 따라 실제 손상 위치를 확인한다.

## 시연과 모델 계약

1. 자동 모드·정지·폐문 상태에서 카 상부 주로프를 클릭한다. 다른 시연·점검·비상정지 중에는 진입을 막는다.
2. 승곰이가 카 상부에서 캘리퍼스를 든 준비 장면을 보여준다. 이 모델에서는 1층을 주출입층으로 가정한다. 카를 해당 위치에 놓고 주도르래에 걸린 구간을 표시한다.
3. 측정기는 치운 채 카를 올린다. 표시 재료는 실제 `wireRopeShape.path`의 호길이를 따라 시브를 넘어 균형추측으로 내려온다. 카 지붕 위 0.90m에 표시점이 오는 카 위치를 기존 경로에서 역산한다.
4. 정지 후 승곰이가 영점을 조정하고, 3번 로프의 미마모부와 마모부 두 방향을 양손에 든 캘리퍼스로 측정한다. 실제 강도·수명 계산이 아닌 **교육용 예시 측정값**이다.
5. 소선 파단·변형·부식, 장력 균일성 확인 안내를 거쳐 지름 기준 결과를 보여준다. 이 두 단계는 확인 항목 안내이며, 파단 수 판정이나 실제 장력값을 계산하는 기능은 아니다.
6. 종료·×·Escape·정지 버튼으로 원래 카/균형추 위치와 층·카메라·로프 표시를 복구한다. 공통 `DemoPause`의 일시정지와 화면 관찰을 지원한다.

`EXAMPLE`이 예시 수치의 원본이다. 미마모부 12.20mm, 마모부 두 방향 10.90/10.80mm → 평균 10.85mm로 비교 → **88.93%, 지름 기준 미달**. 기준 지름은 10.98mm 이상이다. 기존 모델의 공칭 Ø12mm로 분모를 대체하면 경계 판단이 달라지는 예시다. 다른 손상 항목을 생략하고 로프 전체를 합격 처리하지 않는다.

`S`, 로프 경로·끝점·피벗·운행 FSM은 변경하지 않았다. 표시점은 카측 시브 접점을 호길이 원점으로 하며, 1:1의 카 상승량만큼 재료 위치를 균형추 방향으로 이동시킨다. 3번 로프 확대 중에만 원래 균형추측 하강 메시를 숨기고 상하 직선부와 0.24m 꼬임 확대 구간을 표시하며, 단계 종료·중단 시 원래 표시를 복구한다. 형상·재질은 첫 실행 때 생성하고 재사용한다.

연결 파일은 `index.html`(로드·build·update), `js/ui.js`(도어/운행 가드·정지 복귀), `js/demo-pause.js`(공통 일시정지), `js/part-glow.js`(시연 중 다른 부품 강조 억제)다.
