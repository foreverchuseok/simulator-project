# 현장 사진 기반 3단 착상기와 차폐판

2026-09-11 사용자 제공 현장 사진 102129/102133/102139/102217/102219/102145를 기준으로 변경했다. 별도로 지정한 150852/150849 스크린샷은 경로에서 찾지 못했지만 기존 GLB와 생성 스크립트, 첨부된 현장 사진으로 현재 형상을 확인했다.

## 형상과 배치

- 층마다 레일 고정 평판 1개, 카 톱빔 앞쪽에는 슬롯형 센서 3개를 세로로 쌓았다. 금속 몸체·검정 커버·작은 표시등·명판·후면 케이블 고리·흰색 결속부와 공용 세로 랙을 재현한다.
- 기존 차폐판의 표면 구멍/가짜 장공/볼트/돌출 립을 없앴다. 평판 고정부는 센서 입구 뒤쪽에 남겨 이동 중 슬롯을 막지 않는다.
- 평판 164×130×2mm, 센서 피치 80mm, 슬롯 폭 12mm는 사진 비례를 현재 카에 맞춘 시뮬레이터 치수다. 사진만으로 실제 제조 치수나 모델명을 확정한 값이 아니다.
- 좌측 레일에서 검출축을 전면으로 350mm 옮겨 가이드슈와 종단 캠을 피했다. 카 취부 암은 톱빔 전면 웹에서 낮게 나와 난간 베이스 아래로 지나간다. 차폐판 양면과 슬롯 사이 간격은 각각 5mm다.
- 단일 수치 원본은 `index.html`의 `LCD_*`. `blender/scripts/leveling_vane.py`가 숫자 상수를 직접 읽어 GLB를 생성한다. 카측은 `js/leveling-sensors.js`가 같은 상수를 사용한다.

## 차폐 상태

`elevatorState.leveling`에 `upper`, `middle`, `lower`, `atLevel`, `floor`, `offsetM`을 노출한다. 각 센서의 `userData.blocked`와 붉은 표시등도 같은 상태를 따른다. `refreshRopes()`에서 갱신하므로 운행/점검 이동에 따라 바뀐다.

| 카 위치(공용 정지 좌표 기준) | 상/중/하 차폐 | atLevel |
|---|---|---|
| 10mm 아래 | 1 / 1 / 0 | false |
| 정위치 | 1 / 1 / 1 | true |
| 10mm 위 | 0 / 1 / 1 | false |
| 200mm 위·아래 | 0 / 0 / 0 | false |

판의 실제 GLB 바운딩박스로 판정한다. 가로 방향이 어긋나도 신호가 생기지 않는다. 현 치수의 세 채널 동시 차폐 구간은 정지 좌표 ±2mm다. 이는 시뮬레이터의 기하학적 판정 범위이며 실제 착상 허용오차나 센서 응답 정밀도를 뜻하지 않는다.

사진만으로 NO/NC, 광학/자기 검출 방식, 각 신호의 제조사 명칭과 제어 시퀀스는 확정하지 않았다. 현재 자동운전 FSM과 문 열림 조건을 이 신호로 교체하지 않으며, 기존 운행 좌표를 기준으로 판·센서를 정렬했다. 실제 카 바닥 마감 4mm는 기존 모델 상태다.

## 검증

`node tools/verify_leveling_vane.mjs`로 4층의 정위치 및 ±10/200mm 신호, 슬롯과 평판의 실제 메시 간극, 옆으로 어긋난 경우, GLB 로드 오류를 확인한다. `.shot-leveling-slot.png`, `side.png`, `above.png`는 센서 슬롯과 브라켓을 보는 절개 검증 시점이다. 일반 화면은 `index.html?lcdcam`에서 확인한다.
