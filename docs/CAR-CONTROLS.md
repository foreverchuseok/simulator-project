# 카 탑 박스 · OPB · 하중 스위치

참고: 로컬 `부품설계.pdf` 221–223페이지. 구현: `js/car-panels.js`의 `buildCarControls()`.

## 현재 외형

- 카 탑 박스: 상부 난간 왼쪽 앞 안쪽의 금속함, 뚜껑 이음, 난간 체결 브라켓 4개, 하부 케이블 인입.
- OPB: 출입구 리턴 실내면에 금속 세로 판넬, 검정 표시부, 원형 호출 버튼, 1–4층 버튼, 열림/닫힘 버튼, 하부 서비스 커버. 사용자 요청에 따라 표시 숫자는 고정된 4다. 현재 운행층 표시나 클릭 조작과는 연결하지 않았다.
- 오버로드: 플랫폼 아래의 감지 볼트, 플랭크 전면에 연결된 취부판, 50%·110% 스위치 2개와 배선. 볼트와 플런저 사이의 작은 간격을 가진 무부하 외형이다. 임계 하중 측정이나 과부하 운행 차단은 아직 구현하지 않았다.
- 모든 부품과 배선은 카 부모 그룹을 따라 이동한다. 기존 추락방지 안전기 GLB, 작동 샤프트, 로프, FSM은 변경하지 않는다.

## 222–223페이지 전기 연결 관계 메모

도면의 카 탑 박스 보드에서 메인 OPB로 COP–CJB 케이블이 연결된다. 도면 표의 메인 연결 표기는 CN_T1/T2/T4/T15/T19이며, 보조 OPB는 CN_T16, 장애인 OPB는 CN_T17을 통해 CAN 통신 케이블로 연결된다. 메인 OPB와 장애인 OPB 외형을 배치했으며 전기 동작은 연결하지 않았다.

## 장애인용 측면 조작반 (2026-09-11)

- 디자인: [현대엘리베이터 NEO 공식 카탈로그](https://www.hyundaielevator.com/upload/product-catalog/k_neo.pdf) PDF 6페이지의 OPDNB210 금속 표판·원형 버튼·노란 호출 버튼을 참고해 4층용 가로 배열로 재구성했다. 제품의 정확한 치수 복제는 아니다.
- 배치: `carAccessibleOPB`, 불투명 -X 벽의 실내면, 마감바닥에서 모든 버튼 중심 850mm. 진입방향은 -Z이므로 -X 벽은 진입 우측이다. 버튼 1–4, 열림, 닫힘, 비상통화 총 7개. 손잡이와 겹치지 않으며 출입구 모서리로부터 400mm 이상 떨어진다.
- 근거: [편의증진법 시행규칙 별표 1 제9호](https://www.law.go.kr/LSW/flDownload.do?flSeq=46378893)의 조작설비 높이 0.8–1.2m, 휠체어 조작반 0.85m 내외/진입 우측/가로형/손잡이 비간섭을 반영했다. 링크는 2018-02-09 개정 별표이며 이번 작업은 조작반의 형상·배치 기준 적용이다. 건축허가일별 승강기 전체 검사 적합 판정은 하지 않는다.
- 점자: 국립국어원 [점자 편의시설 표준 지침서](https://m.korean.go.kr/common/download.do?c_file_name=2c57877a-7f17-4eda-af71-718b05358b71.pdf&file_path=etcData), 6.4–6.6에 따라 버튼 하단 부착형으로 통일했다. 층 숫자는 수표와 숫자, 기능은 개·폐·호출로 표기한다. 점형은 [한글 점자 표기](https://korean.go.kr/front/page/pageView.do?mn_id=205&page_id=P000302)를 참고했다. 점간격 2.5mm, 자간 6mm, 지름 1.5mm 반구 돌기 형상이다.
- 현재 기존 OPB처럼 외형만 구현했다. 실제 눌림·층 선택 점등·음성 안내·비상통화 동작은 미구현이므로 전체 장애인 검사기준 충족으로 간주하지 않는다.
- 검증: `node tools/verify_car_panels.mjs --accessible`. 850mm 높이, 실내 방향, 불투명 벽, 손잡이 비간섭, 출입구 이격, 점자판 수와 확대 렌더 확인.

223페이지에서는 하중 스위치를 세이프티 디바이스 취부홀에 고정하고, 해당 하중에서 감지 볼트가 스위치에 접하도록 조정한 뒤 OPB 내부 COP 보드의 CC26에 연결하도록 설명한다. 그림에는 50%와 110% 두 기준이 표시되어 있다. 이 페이지들만으로 접점 NO/NC, 핀 배치, 50% 신호의 제어 용도, 실제 하중-변위 보정값까지 확정할 수는 없다. 향후 전기 동작 구현 시 해당 회로/제어 자료를 추가 확인한다.

검증: `node tools/verify_car_panels.mjs`. 4층 구성, 하부/상부 배치, 기존 판넬 간극과 층별 추종, OPB·카 탑 박스·오버로드 확대 화면을 확인한다.
