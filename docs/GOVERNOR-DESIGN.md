# 조속기 형상과 작동점

## 2026-10-02 시작 위치 자동 준비

- 조속기 시연의 3층 이상 사전 호출 조건을 제거했다. 1·2층에서도 누르면 카/균형추·시브·로프를 시연 시작 높이에 자동 배치하고 주로프 부식·파단부터 보여준다. 3·4층에서는 해당 층에서 시작한다. 문이 열려 있으면 먼저 닫고 실행한다.
- 기존 파열 2.4초·절단 후 관찰 2초와 조속기 타격/링크/쐐기·종료 구출 흐름은 유지한다. 운행·고장·다른 시연 중의 차단은 유지한다. `tools/verify_overspeed.mjs`의 첫 실행은 1층에서 직접 눌러 자동 배치와 전체 과속 흐름을 검증한다.

## 2026-10-02 PC 조속기 가속 관찰 보완

- PC에서 가속은 카 낙하 원경에만 나타나고 조속기 확대가 타격 직전에 시작되어 순서를 알아보기 어렵다는 피드백을 반영했다. 시연 시작 때 화면 폭 900px 이상·정밀 포인터인 경우에만 `desktopGovernor`를 적용한다.
- 확대가 끝난 뒤 2.4초 동안 닫힌 진자로 한 바퀴를 점차 빠르게 회전하고, 기존 6.2초의 진자 개방 → 실제 면 접촉/스위치 타격 → 톱니 결착 → 캐치슈 파지로 이어진다. 파지 후 관찰은 PC 1.5초, 모바일 기존 0.55초다. PC 조속기 확대 관찰은 약 10.1초다.
- 추가 한 바퀴는 교육용 느린 동작이다. 열린 진자가 스위치를 통과하지 않도록 PC 낙하 원경에서는 진자를 닫아 두고 확대 가속 후에 연다. 기존 휠 회전량에 따른 카·균형추·로프 연동을 사용하며 형상·타격 곡선·피벗·최종 접점 각도는 유지한다. 모바일에는 추가 회전이나 재생 시간 변경을 적용하지 않는다.
- `js/elevator.js`의 `governorTrip()`에 선택적인 `runUpSeconds`를 두고 `js/ui.js`의 하강 시연에서만 지정한다. 중간 취소는 기존 단일 트립 타임라인을 종료하고 복귀한다. 두 스크립트의 캐시 키를 함께 갱신한다.
- `verify_overspeed --live --shadows` PC와 `--mobile` 390/320px 통과. PC 가속 2.377초·타격/래치 1.680초·파지 관찰 1.494초와 단계 순서, 닫힌 진자/스위치 미접촉 가속, 반복·중단·구출 복귀를 확인했다. 모바일에는 가속 단계가 없고 기존 동작을 유지한다. 오류 0건, 실제 휴대폰 검증은 별도다.

## 2026-10-01 타격 접촉·파단 관찰 시간 보완

- 피드백: 진자 뭉치와 스위치의 타격 위치/동작이 어긋나고, 모바일에서 파손 장면을 알아보기 전에 다음 장면으로 넘어간다.
- 종전 중심점 방위만 맞추고 즉시 ±75°로 꺾던 동작을 대체한다. Python의 실제 네모 머리 외곽(`STRIKE_HEAD_SIZE`·`STRIKE_OUTLINE`)과 액추에이터 판 외곽(`ACT_OUTLINE`)으로 첫 면 접촉을 찾는다. 상·하 방향의 접촉 위상과 밀기 회전각을 각각 GLB `switchStrikeDown`·`switchStrikeUp`으로 내보낸다. 런타임은 곡선을 보간하며 형상/충돌 계산을 매 프레임 생성하지 않는다.
- 하강 `governorTrip()`: 접근 2.2초 → 면 접촉에 따른 밀기 1.1초 → 뭉치가 빠진 뒤 래치 0.6초 → 톱니/캐치슈 파지, 전체 6.2초. 종전 3.2배속을 제거했다. 접점 차단 각도에 도달한 뒤 모터 차단/ESTOP 표시를 반영한다. 상승도 별도 첫 접촉 위상에서 1.1초 밀기 → 0.6초 래치 → 1.4초 관찰 후 로프브레이크로 전환한다. 최종 수평 기준 ±75°, 기존 피벗·정상 회전 간극·로프 파지 위치는 유지한다.
- 주로프: 확대가 끝난 뒤 1.2초 관찰 → 2.4초 연속 파열 → 끊어진 끝을 2초 보여준 뒤 낙하 화면으로 전환한다. 절단 확대 카메라를 가까이 옮기고, 파열음도 같은 재생 시간에 맞췄다. 종료 화면 첫 사진은 절단된 끝을 보여준다. 준비/파단 관찰/타격 도중 복귀도 카메라·예약 콜백·기구를 정리한다.
- 상승/하강 폭주 계산에서 50ms 상한으로 경과 시간을 버리던 부분을 제거하고 같은 GSAP 경과 시간으로 이동한다. 하강 변위는 `v·dt + ½a·dt²`로 계산한다. 낮은 프레임 속도에서 PC 이동만 늦어지는 차이를 없애며, 정격 1.3배 검출과 카/균형추 연동은 유지한다.
- 검증: `tools/verify_governor_switch_contact.mjs`가 실제 GLB 삼각형과 상·하 밀기 접촉을 비교하고, 실제 타임라인의 접촉 전 정지·밀기·래치를 검사한다. `verify_overspeed`는 절단 관찰 시간·반복 효과 버퍼 재사용·중간 복귀를, `verify_ascent`는 파손 관찰 시간과 벽 가림을 확인한다. `node tools/verify_demo_timing.mjs`는 PC/390px 및 10Hz 시뮬레이션 틱에서 재생 시간·검출 위치를 비교한다. 실기기 조작·음향 체감은 별도 확인 대상이다.
