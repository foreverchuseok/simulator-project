# ARD 자동구출운전 시연

사용자 요청 2026-09-29, 참고 화면 `233303`. 사진의 기존 파란 `ARDInstallation` 모델에 배터리 아이콘 `#ard-action`을 붙인다. 형상·치수·GLB는 변경하지 않는다.

- 원본: `js/ard-demo.js`, 연결: `index.html`의 build/update 및 `js/ui.js`의 명령 차단·정전 음성. `sound/announce_power_failure.mp3`는 기존 안내와 같은 SunHi 한국어 음성, “정전입니다. 정전입니다.” 약 4.1초다.
- 자동 모드에서 현재 위치부터 층간 거리의 48%를 이동한다. 진행 중 운행 방향을 이어받으며 종단 여유가 부족하면 반대 방향을 선택한다. INS·BYPASS·안전장치 정지·다른 시연·잠금 불량·사다리 미고정 상태는 시작을 거부한다.
- 정상 이동 → 급정지·정전 화면/음성 → 기계실 ARD 강조 → 카내 정면 시점과 비상등 → 최근접 층 서행 착상 → 카문/승장문 동시 개문 → 첫 대기/폐문 시작 → 승강곰이 폐문 완료 직전 열림 버튼 조작 → 재개문/승강장으로 탈출 → 폐문 → 승강장에서 닫힌 카를 보여주며 종료한다. 2026-09-30 사용자 수정으로 이전의 완전 폐문 뒤 재조작·암전 종료를 대체한다.
- 두 번의 **표시 시간 10초**를 각각 **실시간 3.45초**로 압축한다(기존 3초보다 15% 길게, 숫자 간격 0.345초). 화면에도 시간 압축을 명시한다. 실제 장치의 10초 이상 개문 시간을 구현한 것이 아니라 교육용 연출이다.
- 중앙 네모 안내의 제목/숫자를 기존 약 60%로 축소했다. PC 제목 21→13px·숫자 46→28px·폭 540→324px, 모바일 제목 18→11px·숫자 36→22px. 큰 `정전입니다` 효과는 유지한다. 시연 중에는 별도 중단 버튼을 네모 상자에 중복 표시하지 않고 기존 STOP을 사용한다.
- 열림 버튼은 사용자가 누르는 UI가 아니라 승강곰이 자동 조작한다. 폐문 시작 0.65초 뒤, 남아 있는 실제 문 개방량에서 기존 폐문 타임라인/콜백을 중단하고 재개방한다. 완전히 열린 다음 출입구 중앙 X=0을 통과해 승강장으로 이동하고 문 옆으로 비킨다. 이동 2.85초 뒤에도 개문 시간 3.45초가 끝날 때까지 기다렸다가 닫는다.
- 종료 후에도 호출은 차단하고 `전원 복구 · 시연 종료`를 눌러야 정상 운행으로 복귀한다. 정지 버튼은 시연을 중단하고, 복구 명령은 문을 닫고 최근접 층에 착상한다. 취소 시 예약 작업과 이전 도어 콜백을 무효화한다. 출구를 지나는 중 중단/복구하면 캐릭터를 먼저 원래 위치로 복귀시킨 뒤 폐문한다.
- 기존 `CarDoor`, `rescueToNearestFloor`, `spinSheaves`, 로프 갱신을 공유한다. `S`, 센서 배치, 로프 경로, 균형추 계약은 유지한다. 카메라·일반 조명·환경 반사·비상등·마스코트 상태는 시작 때 저장하고 복구 때 되돌린다.
- 검증: `node tools/verify_ard.mjs`. PC/390px 터치 에뮬레이션의 상승·하강·운행 중 진입·최근접 층·개폐 반복·호출 차단·중단 복구·음원 실제 재생·동일 시점 성능과 캡처를 `.shot-ard/`에 남긴다. 실제 모바일 기기 조작·음량·성능 확인은 별도다.
- 2026-09-30 수정 검증 통과: 축소된 안내·3.45초 대기·폐문 완료 전 반전·승강장 도착 후 폐문·PC/390px 마지막 구도를 확인했다. 출구를 지나는 중 STOP 시 캐릭터 정지, 복구 시 원위치 복귀 후 문 잠금까지 확인했고 브라우저 오류는 0건이다.
